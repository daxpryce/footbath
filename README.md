# Footbath

This is a working title for a python project to pull the Washington State Legislature public data from [Washington State Legislative Web Services](https://wslwebservices.leg.wa.gov/) and store in a local sqlite database.

The database can then be used directly for analytics and reporting, either directly via [SqlAlchemy](https://www.sqlalchemy.org/) or as bulk data analysis via [Polars](https://pola.rs/).
